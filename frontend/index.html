Developer & AI Agent Integration

Connect DepShield AI to VS Code Copilot Agent or use it as a terminal wrapper.

1. VS Code Copilot Agent (.vscode/mcp.json)

Start the MCP server with python -m depshield.mcp_server and add this config:

{
  "servers": {
    "depshield-ai-firewall": {
      "type": "http",
      "url": "http://127.0.0.1:8001/mcp"
    }
  }
}

2. CLI Drop-In Wrapper (depshield install)

Audits packages before invoking pip install:

# Block slopsquatted package before pip runs
python -m depshield.cli install reqeusts-auth-utils

# Audit requirements.txt in CI/CD
python -m depshield.cli audit-manifest requirements.txt
